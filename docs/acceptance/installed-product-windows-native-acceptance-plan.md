# Windows 安装候选的原生验收执行边界

状态：执行计划，2026-10-27 已按 owner 批准执行一次本机开发安装及一次限定恢复；安装已产生受保护目录和四个 SCM 注册，Host 启动失败后保留现场，不是 IP PASS 报告。实测与失败边界见[本机安装报告](installed-product-windows-native-install-20261027.md)。承接 requirements/18 与当前安装候选报告。候选必须先核对准确路径、SHA-256、六程序清单和编译回执，不能用旧候选覆盖新代码。

## 1. 需要另行批准的本机操作

批准后才以管理员/UAC 启动指定的开发候选，使用安装器的固定目录 `C:\Program Files\ForMe` 与 `C:\ProgramData\ForMe`。安装前只核对这两个确切目录是否为空/不存在、固定服务是否未注册和所需端口是否可用；已有内容或服务一律停止，不能清空、接管或自动重新设置其 ACL。

允许的安装副作用应明确限定为：该候选的程序/静态资源和受保护产品目录、固定四个 SCM 注册项 `forme-host`、`forme-web`、`forme-brain`、`forme-release-updater`，以及安装器已定义的服务账户/Service SID、ACL 与恢复策略。前三个是业务服务，updater 是按需维护服务，不增加第四个大脑。初始化阶段只启动 Host/Web，未认领/未配置的 core 不伪装 Ready。

不修改本仓库 `.forme`、现有个人 workspace、模型配置、用户凭据、Developer Mode、系统防火墙或证书信任。测试账号/数据须独立；provider 密钥由 owner 在本机产品界面配置，不进入聊天、源码、截图或报告。未签名候选只能用于本机受限开发验收，不能通过正式签名/IP01 发布门。

## 2. 按顺序保存的证据

1. 包输入与基线：源码提交、包/UI 摘要、签名状态、系统版本、服务/端口和目录前置状态；现有数据不作迁移。
2. 安装与未配置启动：安装器步骤回执；SCM 独立核对注册 image、账户、Service SID、恢复策略和实际 PID；在 `http://127.0.0.1:8765` 验证初始化可达，core 尚未 Ready。
3. 认领与配置：仅使用新测试 owner，验证本地证明、并发/重放拒绝、账号登录、配置 revision/实际 provider、维护和主脑身份绑定。
4. 非交互工具：经最终 plan/审批调用文件 worker，独立核对低权限 token、隔离文件/网络访问、私有副本、Host exact writeback、加密结果、真实脑事件和副作用计数；拒绝/重放必须为零新增副作用。
5. Web 与恢复：实际浏览器对话/项目/收件箱/认知/设置，断线与双 tab、Web/core 分别重启、core 离线备份核验、原命令核实；不以模型文本自报验证 memory/工具。
6. 服务生命周期：冷启动、注销和崩溃后仍常驻，按有限策略恢复；这些会影响当前桌面会话，执行前与 owner 协调，不能在无人确认时注销/重启系统。
7. 已批准的升级/恢复候选：签名和兼容性预检、排空/备份/一次性 updater 接管、活动程序与数据核验、健康后恢复准入；错误/中断保留原操作及 Unknown，不自动重做。
8. 卸载：另行确认准确目标；移除固定服务/程序并默认保留脑、备份和恢复说明，不把数据清除纳入默认卸载。

桌面 helper 未实现或未经原生验收时，IP11 保持 NOT_RUN/UNVERIFIABLE。完整 IP24 不能由上述部分成功、临时进程或前端模拟转成 PASS；Linux/macOS 保持既有不发布边界。

## 3. 回退与留存

任一步失败停止后续变更并保存安装/产品 journal、原配置、已观察 SCM 状态、包摘要和安全错误引用。写入或副作用不明时不重新运行安装器、不换 operation，也不自动删除目录；使用已经批准的显式诊断/恢复路径。移除本轮新增服务/程序、重试或卸载另需确认具体操作，原件和 Unknown 证据保留。

验收报告按 `PASS / FAIL / UNVERIFIABLE / NOT_RUN / NOT_APPLICABLE` 逐 IP、逐平台填写，记录哪些动作实际执行。报告不含口令、cookie、bootstrap proof、provider key、原始 session token、截图中的个人内容或私有数据正文。
