# 归档文档

本目录保存 forme 早期的规划与架构基线文档。它们记录了设计是如何一步步推导出来的，但其中的阶段划分、对象命名、M0 切分和“下一步”表述已经被后续文档修正或取代。

**口径说明**：归档文档不是现行设计依据。任何同名对象、等级、边界或判断，以 `../architecture/canonical-contract.md`、`../requirements/` 和 `../architecture/02-09` 为准。归档文档不再更新。
